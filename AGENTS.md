# Convenciones de Ordia

- Trabajar por etapas: implementar únicamente el alcance solicitado para la etapa actual.
- Mantener la interfaz y la documentación en español.
- Usar React, TypeScript, Vite, pnpm y Tailwind CSS.
- Separar páginas, componentes, servicios y tipos; priorizar componentes pequeños y accesibles.
- No simular funciones: cualquier módulo aún no implementado debe mostrarse como pendiente.
- No incluir secretos en Git. Las variables públicas documentadas viven en `.env.example` y los valores locales en archivos `.env*` ignorados.
- Antes de cerrar una etapa, ejecutar `pnpm typecheck`, `pnpm lint`, `pnpm test` y `pnpm build`.
